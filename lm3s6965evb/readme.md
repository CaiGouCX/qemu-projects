# 🚀 LM3S6965EVB 电机控制工程

本工程基于 **QEMU + LM3S6965EVB (Cortex-M3)**，实现了一个 **中性能电机控制** 框架，核心为 **速度环 PID + PWM 输出**,很多地方为了过编译是空函数实现。  

---

## ✅ 已实现功能

- [x] **速度环 PID 控制**（支持浮点 / 软件浮点 / 定点 Q15 三种版本）  
- [x] **PWM 占空比输出**，带方向控制  
- [x] **MOVE / HOLD 状态机**  
- [x] **工程结构清晰**，模块划分：  
  - `pid.c` / `pid.h` → 控制算法  
  - `actuator.c` → 执行器（PWM 驱动）  
  - `system_comm.c` → 系统初始化与命令处理  
- [x] **可编译运行**，通过 QEMU 测试验证  

---

## ⚠️ 待补充功能

### 1. 时间与性能测量
- **目标**：确保中断执行时间 < 控制周期  
- **方法**：  
  - 使用 `DWT->CYCCNT` 测量 PID 函数执行时间  
  - 或在 ISR 入口/出口翻转 GPIO，用示波器测量脉宽  

---

### 2. PID 改进
- **积分防风**：给积分项设置上下限，防止长期累积导致失控  
- **输出饱和保护**：PID 输出需限制在 PWM 最大占空比范围内（0–100%）  
- **参数一致性**：定点与浮点版本的缩放系数需统一文档说明  

---

### 3. 错误与安全保护
- **过流/过速/欠压** 检测（硬件或软件模拟）  
- 运行异常时进入 **安全状态 (HOLD)**，关闭 PWM 输出  
- 启停逻辑需支持 **软启动/软停止**，避免突变  

---

### 4. 调试与监控
- **UART 输出**：实时打印速度反馈、PID 输出值，便于调参  
- **状态机指示**：通过 LED 翻转或串口信息显示当前状态（MOVE/HOLD/ERROR）  

---

### 5. PWM 驱动优化
- 确认 **死区时间** 配置，避免上下管直通  
- 在 **定时器中断 / PWM 更新中断** 中合理区分速度环和电流环的执行位置（未来扩展）
